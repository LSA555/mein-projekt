# Designplan CYSPA-Website (Teil 1: Tokens und Grundsätze)

Task: NGL-20261104-368091. Layouts je Seitentyp folgen nach S1 (Inhalte cyspa.ch, Struktur infoguard.ch).

## Farbe
| Name | Hex | Einsatz |
|---|---|---|
| Navy Deep | #071828 | Hero, Footer |
| Navy | #103157 | dunkle Rhythmus-Sektionen, Logo auf hell |
| Gold | #ffc000 | CTA, Gold-Kante, Ticks. Nie Fläche, nie kleiner Text auf Grau |
| Primary Blue | #425b76 | Section-Labels |
| Ink / Body | #1a1a1a / #5a5a5a | Text auf hell |
| Gray / Border | #f8f8f8 / #e6e6e6 | Sekundärflächen, Linien |

## Typografie
Raleway, eine Familie. Headlines 800 mit leicht negativem Tracking, Body 500.
Zweizeilige Headlines nach CI: Zeile 1 Prämisse (Navy), Zeile 2 Drehung (Ink).
Keine Versal-Eyebrows über jeder Überschrift; Section-Labels nur, wo sie Orientierung geben.

## Layout-Grundsätze
- Rhythmus hell / Navy wechselnd, Navy Deep nur für Hero und Footer.
- Signatur: Gold-Kante links an dunklen Flächen (aus Fakten-Karte und Social-Formaten). Das ist das eine
  markante Element. Alles andere bleibt ruhig.
- Struktur von infoguard.ch übernommen (Navigationslogik, Reihenfolge der Startseiten-Sektionen),
  keine Texte, Bilder oder Formsprache von dort.
- Notfallkontakt dauerhaft sichtbar in der Kopfzeile, sofern CYSPA einen anbietet (zu klären).
- Zahlen nur mit Quelle (Copy-Regel CI §2).

## Copy-Regeln
Sie-Form, aktiv, ohne Angstrhetorik. Kein Gedankenstrich im Satzfluss, ss statt ß, keine Ausrufezeichen.

## Qualitätsboden
Responsiv bis 360 px, sichtbarer Fokus (Gold-Outline), reduzierte Bewegung respektiert, Kontrast 4.5:1.
